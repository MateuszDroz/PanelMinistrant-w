Czas systemowy (test RFID/mszy)

—

Po ustawieniu np. niedzieli 09:50 system zaliczy mszę w oknie −1h…+2h od stałych godzin mszy. Widoczne tylko dla konta 1.

📡
Awarie / błędy ESP32 (RFID)
Ustawienia → ta karta · błędy z czytników (WiFi, HTTP, JSON…)

Kliknij „Odśwież błędy”, aby pobrać logi z serwera.

Czytnik wysyła ?action=err&device=…&kod=…&msg=… do skryptu GAS. Serwer trzyma ostatnie ~30 wpisów w Script Properties (rfid_bledy_urzadzen). Lista jest pusta, dopóki ESP32 nie zgłosi błędu (firmware musi to wywoływać).
